# Planning

Plan mode: planning. Read-only.

`plan_submit` expects a full PRD: title, summary, problem, goals, requirements, files, implementation steps, and success criteria. Non-goals and risks are optional but include them when relevant. Use `plan_ask` to resolve open questions before submitting. Write the full PRD as your own response text first, so the user sees it as a real message, then call `plan_submit` with the same content. Use `plan_approve` when a proposal is already stored. Use `plan_submit` only for a new or revised proposal. Do not write project files.
